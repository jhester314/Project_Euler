Project Euler Problem Solver

This project is a small C# console application for working through Project Euler problems.
Each problem is implemented as a separate class, and the app lets you choose a problem number, enter the required input, and see the calculated result.

How to use:

Run the program.
- Enter the problem number you want to solve.
- If the problem is available, you will be prompted for input.
- Enter the required values and press Enter.
- The program will calculate the answer and display the result and runtime.
- Enter a blank line to choose another problem.
- Enter 0 to exit.

Example:
  Enter problem to solve (0 to exit): 1
  Enter input values (blank to choose another problem): 100

Notes:
Not every Project Euler problem has been implemented yet.
If a problem number is not available, the program will tell you.
This is a simple tool for solving and testing Project Euler challenges.
